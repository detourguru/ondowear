## 프로젝트 설명
기온에 맞는 옷차림과 소지품을 추천해주는 현재위치 기반 웹앱 서비스입니다.

스타일과 위치를 모두 지정 후 `/main` 화면에서 날씨 및 소지품 정보를 확인하실 수 있습니다.


## 배포 링크
https://ondowear.vercel.app/main

## 시작하기

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
